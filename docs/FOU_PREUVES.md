# SafeSea - Preuves FOU

## Preuves techniques

- Depot GitHub public.
- Application deployee sur Vercel.
- Workflow CI GitHub Actions.
- Schema Supabase.
- Captures desktop et mobile.
- Demonstration de la carte.
- Demonstration d'un signalement.
- Demonstration de la checklist.

## Preuves citoyennes

- Explication du besoin : securite des plaisanciers et entraide maritime.
- Public cible : plaisanciers, pecheurs, clubs nautiques, ecoles de voile, debutants.
- Contribution : prevention, partage d'alertes, sensibilisation, protection du milieu marin.
- Absence de proselytisme ou d'objectif discriminatoire.
